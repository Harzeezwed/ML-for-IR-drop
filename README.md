# ML for IR drop
Power integrity is a critical challenge in modern VLSI design, particularly as technology scales and designs grow in size and complexity. A significant power integrity issue is static voltage drop (often referred to as IR drop), caused by resistive losses in the power delivery network (PDN). Excessive voltage drop can lead to timing failures, functional errors, and reduced reliability, often requiring costly design iterations late in the design cycle. Today, accurate voltage drop analysis relies on computationally expensive signoff tools that are typically run late in the design process, when mitigation options are limited and costly. Designers lack fast, early-stage prediction methods that can identify IR-drop hotspots during placement and routing, resulting in inefficient design iterations, over-constrained margins, and increased turnaround time. In this challenge, you will develop a machine learning model capable of predicting static IR-drop behavior earlier in the physical design flow, enabling proactive mitigation and improving overall design efficiency.
